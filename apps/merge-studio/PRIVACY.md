# Privacy: Merge Studio

Merge Studio makes no network requests. It has no crash reporting, no
analytics and no usage tracking; it doesn't look up anyone's picture; and it
has no AI features. Reading your conflicts, the three-way merge editor, the
diff, and Continue, Skip and Abort all run on your computer, with your own
git.

The links it offers open in your browser only when you click them. One of
them, **Report a problem** on the Conflicts dashboard, opens a new GitHub
issue with Merge Studio's version, your editor's name and version, and your
platform already filled in, and nothing about your repository. Those facts
are in the page's address, so GitHub receives them when the page opens,
before you decide whether to submit it.

Your editor keeps Merge Studio up to date from the VS Code Marketplace or Open
VSX; Merge Studio never checks for updates itself.

If you see Merge Studio send anything over the network, that is a bug: please
report it privately (see [SECURITY.md](SECURITY.md)).
