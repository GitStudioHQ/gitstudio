# GitStudio 2.5.0 — in 14 languages

## Pick your language

**Settings ▸ Appearance ▸ Language** sets GitStudio's language, or leaves it
on **System** to follow your OS: Simplified and Traditional Chinese, Japanese,
Korean, German, French, Spanish, Italian, Portuguese (Brazil), Russian,
Turkish, Polish and Czech, besides English. A change applies after a restart,
and the setting offers one.

Every screen is translated — Changes, Commits, Branches, the graph, pull
requests, issues, Actions, the Assistant, Settings, menus and dialogs. The
translations other than English are machine drafts made with each language's
own git terms; corrections from native speakers are very welcome as issues or
pull requests.

## What git stores stays in English

Undo's reflog entries, stash messages and the revert commit it makes are
written in English whatever language GitStudio shows, so the repository's
history reads the same for everyone who opens it.

## Fixed

- Counts read as whole sentences ("3 commits to push") in every language.
- Pull request review badges say "approved" or "changes requested" in words,
  not GitHub's raw state.
