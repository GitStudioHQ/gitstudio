# Korean (ko) glossary for GitStudio

Conventions follow git's official Korean po translation (git-scm) and the VS
Code Korean language pack. Loan words written in Hangul transliteration are
used where both git-ko and VS Code-ko keep the English concept as a loan word
rather than a native Korean paraphrase (commit, branch, stash, rebase,
cherry-pick, squash, fixup, tag, hunk, repository, etc.) — this matches how
Korean developers actually talk about git.
