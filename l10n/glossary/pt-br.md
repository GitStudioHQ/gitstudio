# Glossary — Brazilian Portuguese (pt-br)

Sources: git's official pt_BR po translation conventions (git-scm), and VS Code's
pt-br Language Pack conventions. Where both keep a term as an English loanword
(common in Brazilian dev culture), we do too.

Notes:
- "mesclagem"/"mesclar" follows git's official pt_BR translation for merge.
- Most git subcommands used as nouns/labels stay as English loanwords
  (commit, rebase, stash, cherry-pick, push, pull, worktree, tag, stage,
  squash, fixup), matching both git's pt_BR po and VS Code's pt-br pack,
  which keep Git terminology untranslated for developer audiences.
- "fazer checkout" used for the verb when needed by sentence structure.
