# Turkish (tr) glossary

Git terms follow git's own official Turkish translation (`tr.po`, contributed
by Emir Sarı) where it renders a native term; editor/UI terms follow VS
Code's Turkish language pack convention. A few loanwords that Turkish
developer tooling keeps unchanged (e.g. "commit" as a verb in speech) are
still given a native noun here for UI consistency, matching git's own choice.
