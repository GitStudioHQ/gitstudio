# Glossario italiano (it)

Termini git da git-scm (localizzazione italiana ufficiale, po/it.po) dove
disponibili; termini di editor/UI dal pacchetto lingua italiano di VS Code.
Molti termini git restano prestiti in italiano (come fanno git e VS Code) e
sono segnati "invariato" qui sotto.
