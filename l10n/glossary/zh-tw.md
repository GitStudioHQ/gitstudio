# Traditional Chinese (zh-tw) glossary

Git porcelain verbs are translated, following the convention used by Chinese
git tooling and git's own zh_CN translation (adapted to Taiwan word choice —
e.g. 設定 not 设置, 資料夾 not 文件夹, 檔案 not 文件). Editor/UI chrome follows
VS Code's Traditional Chinese language pack conventions (e.g. 工具列, 狀態列,
選單, 貼上, 剪下). Taiwan-specific terms (as opposed to Simplified-Chinese
character conversion) are called out below.

Notes:

- `git` command names, flags and code in backticks are never translated
  (e.g. `git rebase --continue`).
- Product names (GitStudio, Merge Studio, GitHub, VS Code, Cursor, Claude,
  OpenAI) stay in English.
- "HEAD" stays untranslated, matching both git's own usage and VS Code's
  Traditional Chinese pack.
- Generated by converting the finished Simplified Chinese catalog
  (`l10n/zh-cn.json`) with OpenCC's `s2twp` (Simplified → Taiwan, with Taiwan
  phrase substitution) and then correcting the handful of terms where the
  generic Taiwan-phrase dictionary doesn't know this git client's own
  vocabulary (checkout → 簽出 not 檢出, repository → 儲存庫 not 倉庫, stash →
  儲藏 not 貯藏, clone → 複製 not 克隆), plus a couple of OpenCC
  mis-segmentations around 合併/合並 and 了/瞭 that were fixed by hand.
