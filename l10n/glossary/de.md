# German (de) glossary

Conventions: git terms follow git's official German `po/de.po`; editor/UI
terms follow VS Code's German language pack. Loan words that git/VS Code
keep in English are kept here too. Address: neutral/imperative style (VS
Code's German pack mostly avoids direct address; when unavoidable it uses
formal "Sie", never "du").
